# Akaxi Tarot assets

This directory contains the 78 Akaxi Tarot images from:

https://github.com/look-fate/tarot-lab

Source image order:

- `0.png` to `21.png`: Major Arcana, Fool through World
- `22.png` to `35.png`: Wands, Ace through Ten, King, Queen, Knight, Page
- `36.png` to `49.png`: Cups, Ace through Ten, King, Queen, Knight, Page
- `50.png` to `63.png`: Swords, Ace through Ten, King, Queen, Knight, Page
- `64.png` to `77.png`: Coins, Ace through Ten, King, Queen, Knight, Page

The explicit `akaxiImageOrder` array in `app.js` maps that source order to the
app's Page, Knight, Queen, King rank order.

`akaxi-tarot.txt` is the repository's original image URL list.
The repository MIT license is preserved in `LICENSE.txt`. Its README states that
image rights remain with the original artists.
